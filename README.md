# Saumya Patel — Portfolio

A premium, modern, and highly polished personal portfolio website showcasing my journey as a Full Stack Web Developer. This portfolio is designed to be fully responsive, accessible, and features smooth scroll animations with persistent dark and light modes.

## Tech Stack

This project is built from scratch with zero dependencies for maximum performance:
- **HTML5** (Semantic structure)
- **Vanilla CSS3** (Custom properties, grid, flexbox, animations)
- **Vanilla JavaScript** (DOM manipulation, theme toggling, IntersectionObserver)

## Features

- **Theming**: Integrated Light & Dark modes with system preference detection and `localStorage` persistence.
- **Scroll Animations**: Smooth reveal animations triggered seamlessly on scroll.
- **Fully Responsive**: Mobile-first approach ensuring a premium experience on all devices (mobile, tablet, desktop).
- **Zero Dependencies**: Pure web standards, no build step, incredibly fast loading times.

## Getting Started

Since this is a vanilla HTML/CSS/JS project, there are no packages to install or build processes to run.

To view the project locally, simply double-click the `index.html` file to open it in your web browser. 

Alternatively, if you have VS Code installed, you can use the "Live Server" extension for hot reloading:
1. Open the project folder in VS Code
2. Right-click `index.html`
3. Select "Open with Live Server"

## Build

No build step is required! The `index.html` file is ready for production as-is.

## Deployment

This static project can be deployed easily in seconds using platforms like:
- **GitHub Pages** (Recommended)
- **Vercel**
- **Netlify**

Simply connect your GitHub repository to your provider of choice and set the root directory as the deployment source.
